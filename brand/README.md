# Happy Path Apps — brand assets

Everything here is generated by `render_brand.py`. Change the shape or the colours there and
re-run it; do not edit the PNGs, or the profile picture and the cover will drift apart.

```
python render_brand.py
```

## The mark

A path that rises and arrives at a point. It is the name read literally — the happy path is the
route where nothing goes wrong — and it is the only idea in the name that draws.

What it is deliberately **not** is Roadworthy's icon. That one is a number plate in a camera
guide carrying the MOT device, and it belongs to the product. A studio that puts its first app's
logo on its own page has nowhere to go when there is a second one. The two share a ground colour
(`#13181F`, the same `ic_launcher_background` the launcher icon uses) and nothing else, which is
enough to look related.

Rejected on the way: a plain tick (says "to-do list", and says nothing about a path), a smile
drawn as an arc (reads as a mouth at any size), an `hp` monogram (weak, and a printer company
owns those letters), and the mark inside a rounded tile — Facebook and Instagram both crop a
profile picture to a circle, so a tile inside that is a frame inside a frame.

## Colours

| | |
|---|---|
| Ink `#13181F` | ground, shared with the Roadworthy launcher icon |
| Mint `#4ADE80` | the path |
| Off-white `#F7F6F2` | the name |
| Muted `#969EA8` | the tagline |

## What goes where

| File | Use |
|---|---|
| `mark-1024.png` | Facebook page and Instagram profile picture |
| `mark-512.png` | anywhere smaller that wants the square |
| `cover-1640x856.png` | Facebook page cover |
| `favicon-32.png` | site favicon |
| `favicon-180.png` | `apple-touch-icon` |

Both platforms crop the profile picture to a circle, so the mark is drawn with room around it —
checked at Instagram's 320px, Facebook's 180px and the 40px a comment avatar gets.

The cover is a centred lockup rather than one set to the left, because Facebook shows the whole
1640×856 on a desktop and a narrower centred crop on a phone. Anything against an edge is what
gets cut. The profile picture also overlaps the cover's lower left on desktop, which centring
stays clear of.

## The font

Rendered in Bahnschrift, which ships with Windows. It is a DIN derivative, which is why it suits
a studio whose first app reads road signage — but it does mean `render_brand.py` only runs as-is
on a Windows machine. Point `FONT` somewhere else if that changes.
